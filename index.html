      LGA Identifier

      Bulk-identify the Local Government Area (LGA) for a batch of patient suburbs, and get the matching Z0N_ Cliniko tags ready to apply — built for the daily calendar tagging run, so you're not looking each suburb up one by one.

      How to use this

      1. Pull today's list of patient suburbs from the referrals/calendar you're tagging.
      2. Add them below — type each one into the search box and hit Add (or Enter), or paste the whole list at once using "Paste a list instead."
      3. Check the chip list for anything marked (not found) in red — usually a typo or a suburb outside NSW — and fix or remove it.
      4. Click Generate LGA tags. Each result card is one Cliniko tag (Z0N_LGA Name), with the suburbs that matched it listed underneath so you can spot-check.
      5. Click Copy list to copy every tag name to your clipboard, then paste into Cliniko when applying the unavailable block types / appointment types for the day.
      6. Click Clear all to reset once you're done, ready for tomorrow's batch.
